# DOT WORLD

윈도우 98 스타일의 이미지·영상 도형 효과 편집기입니다. 별도 설치나 빌드 없이 `index.html` 하나로 실행합니다.

## 기능

- 사진 불러오기, 원본 비교, 다양한 도형·질감 효과
- 도형 테두리와 두께 조절, 원하는 영역에만 부분 효과 적용
- 추천 색상 15개와 색상별 PNG 전체 ZIP 다운로드
- 사진으로 움직이는 영상 만들기, 기존 영상에 도형 효과 적용
- 영상 세부 설정, 음악·원본 소리 포함 내보내기
- PNG·SVG 저장, 여러 사진 일괄 저장, CMYK 분판
- 모바일 전용 조작 화면과 PC 화면 보기

이미지와 영상 처리는 브라우저에서 이루어집니다. 영상 저장 형식은 사용하는 브라우저 지원에 따라 달라집니다.

## GitHub Pages로 공개하기

1. 저장소의 **Settings → Pages**를 엽니다.
2. **Build and deployment → Source**를 **Deploy from a branch**로 선택합니다.
3. **Branch**에서 **main**, 폴더는 **/(root)**를 선택하고 **Save**를 누릅니다.
4. 배포가 완료되면 Pages 화면에 표시된 링크를 엽니다.

설정 완료 후 기본 접속 주소는 `https://hugopark1110.github.io/dot-world/`입니다. Pages를 활성화하기 전에는 이 주소로 접속할 수 없습니다.

[GitHub Pages 공식 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 파일 수정

`index.html`을 수정하여 `main` 브랜치에 반영하면, Pages가 켜진 상태에서는 사이트가 다시 배포됩니다. `.nojekyll`은 별도의 Jekyll 빌드 없이 정적 파일을 제공하기 위한 파일입니다.
